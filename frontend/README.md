# Frontend React App

This is the frontend for the backend API, built with ReactJS.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   ```

The app will run on [http://localhost:3000](http://localhost:3000).

## Connecting to Backend

Update API URLs in your React components to point to your backend (e.g., `http://localhost:5000`).
